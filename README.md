# GoodLuck Pocket v4.0

タロットカードをモチーフに、今日の市場、季節、曜日、登山・自然・小さな幸運を静かに読み解くAI占いサイトです。Cloudflare Workers + Static Assets + Workers AIに対応しています。

## セットアップ

```cmd
npm install
```

## 開発

```cmd
npm run dev
```

ローカルサーバーが起動したら、表示されたURL、通常は `http://127.0.0.1:8787` を開きます。

## ビルド

```cmd
npm run build
```

`wrangler deploy --dry-run --outdir dist` により、Cloudflare Workers向けのビルドを検証します。

## Cloudflareへのデプロイ

1. CloudflareアカウントでWorkers AIを利用できる状態にします。
2. `wrangler login` で認証します。
3. `wrangler.jsonc` の `name` や `compatibility_date` を必要に応じて確認します。
4. 次のコマンドでデプロイします。

```cmd
npm run deploy
```

### 市場情報の拡張

v4.0では将来の市場データ連携に備え、任意の環境変数 `MARKET_CONTEXT_JSON` をAIプロンプトへ渡せる構造を用意しています。未設定でも動作します。

```json
{
  "watched": ["Gold", "BTC", "USDJPY", "VIX"],
  "notes": ["重要指標前のため待機を意識する日"],
  "source": "manual"
}
```

## カード画像

カード画像は `public/cards/` に配置しています。

- `00.webp` から `21.webp`: 大アルカナ22枚
- `back.webp`: カード裏面

カード画像にはタイトル文字を入れず、カード名はHTML側で表示します。カード情報は `public/data/cards.json` でも確認できます。

## 動作確認

以下を確認してください。

- 生年月日、性別、血液型、利き手を入力して占い結果を生成できる
- 同じ日、同じ入力条件では同じカード・正逆位置・トレード運が表示される
- 翌日には新しい日次結果へ切り替わる
- カードは自動では開かず、クリック後に反転演出で表面が表示される
- カードをめくった後に、今日の運勢、ゴールド運、FX運、登山の運、今日の一歩、カードからのポエム、今日の言葉が表示される
- AI APIが利用できない場合でも今日の言葉が表示される
- API JSONに `todayMessage` と `recommendArticle` が含まれる
- ラッキーカラー、ラッキーナンバーが控えめに表示される
- PC、タブレット、スマートフォン幅でレイアウトが崩れない
- `npm run check` と `npm run build` がエラーなく完了する
